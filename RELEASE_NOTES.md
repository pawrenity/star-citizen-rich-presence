## What's new

- A native Windows control panel with a custom app icon, tray controls, and optional launch at Windows sign-in.
- Pause Discord sharing from the app or tray. Choose which details appear, edit both text lines below the title, and add up to two link buttons in the app.
- Improved location detection from local inventory transitions, ship terminals, ATC contacts, quantum arrivals, and matched route origins. Includes fixes for Checkmate, Ruin Station, Levski, both gateway crossings, and Lorville.
- Location names appear without the “Last seen” prefix. The companion still expires old sightings and falls back to general activity when it lacks a known location.
- Artwork for 37 exact locations from the Star Citizen Wiki, including both Nyx–Pyro gateway stations.
- Hangar status appears on the secondary line so the location stays visible. “In hangar” is inferred from a recent assignment and local ATC contact.

Download the Windows ZIP under **Assets**, extract it, and launch the executable. For an upgrade, quit the old companion first. Desktop preferences carry over.

The companion reads Game.log. Location updates depend on in-game events and do not require OCR, an overlay, or a chat command.

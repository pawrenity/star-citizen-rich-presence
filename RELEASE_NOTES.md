## 3.1.0: Windows installer

- **New installer:** `star-citizen-rich-presence-setup-x64.exe` installs the app for your Windows user without admin rights. It adds Start menu shortcuts for the app, the artwork picker, and the example settings. A desktop icon and starting with Windows are optional.
- **Easy upgrades:** the installer closes a running copy before replacing it, and newer versions install over older ones.
- **Clean uninstall:** remove it from Windows Settings. It asks before deleting your saved preferences, and it only removes the start-with-Windows entry if that entry belongs to the installed copy.
- The portable ZIP is still available.

Everything from 3.0.0 is included: ship artwork, mission icons, party status, your own images, and custom activity types.

Download the installer or the Windows ZIP under **Assets**. Quit the previous companion before upgrading. Desktop preferences carry over.

## 3.1.2: smooth anti-aliased UI, custom dropdowns, and themes

- **Anti-aliased UI rendering:** replaced jagged Win32 GDI shapes with an analytical SDF anti-aliased renderer so toggle switches, knobs, rounded cards, buttons, and status dots look crisp and smooth.
- **Custom dark Fluent dropdowns:** replaced default Win32 comboboxes with themed owner-drawn dropdowns featuring rounded borders, subtle chevrons, and accent-highlighted options.
- **Appearance customisation:** new **Appearance** tab in the sidebar with 4 colour schemes (**Obsidian**, **Midnight**, **Pitch**, **Slate**), 6 accent colours (**Sky**, **Amber**, **Emerald**, **Coral**, **Violet**, **Ice**), and **Rounded / Sharp** corner styles that apply live (including the Windows title bar).
- **Clearer Activity labels:** **Member list shows** options now describe each choice plainly (`Game name (Star Citizen)`, `Line 2 — Location / custom`, `Line 3 — Ship & contract`).

Download the installer or the Windows ZIP under **Assets**, or click **Update now** inside v3.1.1 to auto-update.

## 3.1.3: full wiki ship galleries, image pagination, and silent auto-updates

- **Full Star Citizen Wiki ship galleries:** raised the bundled artwork cap from 16 to **120 pictures per ship** (9,364 choices across 282 ships, including all RSI Galaxy official, concept, and module shots) using compact URL storage.
- **Images page pagination:** added **‹ Prev / Next ›** navigation and a page indicator on the **Images** page so you can browse every picture for every ship.
- **Silent background auto-updater:** clicking **Update now** now downloads, SHA-256 verifies, installs silently in the background with zero prompts, and auto-restarts into the new version (works even from portable copies), and fixed text clipping in the Updates row.
- **Image upload polish:** uses the modern Windows Explorer file picker and surfaces dialog errors if one occurs.

Download the installer or the Windows ZIP under **Assets**, or click **Update now** inside the app.
